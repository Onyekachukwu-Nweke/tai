# TAI - Self-directed Learning Companion

## Development

The M0 foundation is in progress. See [local setup](docs/developer-guide/setup.md) for Google sign-in configuration and verification.

```sh
nvm use
npm ci
npm run db:migrate
npm run dev
```

The preview supports signed-in study-space creation/listing and PDF/TXT previews with private material saving, reopening, and study-space deletion. Learning activities are not available yet.
