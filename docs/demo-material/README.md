# TAI demo material

`tai-demo-case-study.pdf` is an original, synthetic course handout created for
the TAI hackathon demonstration. It contains no learner data or third-party
course content and is released under CC0 1.0.

The editable source is `tai-demo-case-study.html`. Regenerate the PDF with:

```sh
libreoffice --headless --convert-to pdf --outdir docs/demo-material \
  docs/demo-material/tai-demo-case-study.html
```

The case study deliberately includes page-level concepts, a realistic scenario,
and a worked earned-value calculation so the demo can show concept organization,
source citations, recall, rubric feedback, and numeric checking.
